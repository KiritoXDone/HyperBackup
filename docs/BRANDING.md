# HyperBackup 项目图标

状态：**橙白方案已于 2026-11-08 确认为项目图标设计基准。** 后续应用图标资源以此图稿为依据。

![HyperBackup 橙白图标设计稿](../ui/branding/hyperbackup-orange-v1.png)

## 视觉定义

- 橙色圆角方形底，白色存储卡轮廓。
- 存储卡保留左上切角与顶部缺口。
- 一个向右的镂空箭头表达数据传入，简化点状数据流。
- 极简、扁平的 Miuix 风格；以清晰轮廓和小尺寸辨识度为目标。

参考来自 ADB 观察的 DataBackup 2.0.12 橙白图标，选定稿由内置 imagegen 生成。原始 [生成提示词](../ui/branding/prompt.txt) 与图稿共同保留，便于追溯设计意图；提示词中的目标颜色和尺寸不作为栅格文件已严格满足的测量结论。

## 当前资产与后续交付

当前 PNG 是带白色外边距的设计稿。仓库保存原文件，尚未制作 Android adaptive icon 前景/背景分层、monochrome 资源或各密度 launcher 资源。

开始制作应用资源时，按选定轮廓重建可维护的图形资源，分离底色与主体，处理设计稿外边距和系统遮罩，并验证不同启动器形状、主题图标与小尺寸效果。实际资源完成前，不把此 PNG 直接视为已通过 Android 适配验证的最终启动图标。

页面主题以 [UI 规范](UI-SPEC.md) 为准；此图标确认仅确立项目标识资产。
