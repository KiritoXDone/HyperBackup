# 完整业务能力覆盖，支持新建和更新备份集

用户将目标从精简首版改为完整移植固定版本 backup_script 的业务能力，并持续跟进上游。正式首版以逐项覆盖和验证为门槛；未完成版本只能标为预览，不能将未实现能力继续列为正式版排除。保留 KernelSU Miuix 视觉和橙白图标，不要求复制上游壁纸、玻璃和背景动画。

同时提供“新建备份集”和“更新已有备份集”，默认新建保留历史；更新既有集时使用上游 fast-skip 和更新行为，确认页说明会修改所选集。一次执行称备份批次，与可多次更新的备份集分开；不把更新已有目录标成新增历史版本。

代价是范围和验证量增加；收益是产品目标与完整引擎复用一致，后续新增能力不再受旧精简边界限制。本决定替代 ADR-0002 及原首版业务排除项，源中未证实的能力不因此变成承诺。
