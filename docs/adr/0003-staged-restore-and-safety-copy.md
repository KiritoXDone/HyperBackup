# 逐应用下载校验，并默认创建恢复前备份

2026-11-08：被 ADR-0007 替代。下载后恢复仍为默认，直接串流恢复纳入完整覆盖；恢复前副本仍为应用恢复的默认保护。以下内容仅记录原决定。

远端恢复先下载一个应用所需归档并完成校验，再开始修改目标应用；空间不足时阻止，不自动退化为边下载边覆盖。对于已安装的目标应用，默认先保存恢复前备份且确认成功，用户可在确认页明确关闭。

该取舍增加临时空间、存储用量和耗时，以降低损坏归档或网络中断直接影响现有数据的概率。它不提供整批原子恢复，不保证失败自动回滚，不能解决不可迁移的设备密钥或应用服务端登录约束。恢复前副本失败或未确认提交时，不允许进入对应应用的覆盖步骤。
