# 每次备份保留独立批次，首版手动清理

2026-11-08：被 ADR-0006 替代。现在支持新建和更新备份集，默认新建；更新既有集时保留上游 fast-skip 与清理语义。以下内容仅记录原决定。

刷机恢复需要能选择之前的状态，用户没有必须兼容的旧备份，因此选择每次生成独立批次、保留多次应用备份，不以原位置覆盖作为默认存储模型。首版手动清理，不加入自动保留策略或块级增量去重；代价是更多存储占用，需要展示批次大小和不完整项，并防止清理影响运行中的任务。

独立批次并不等于全批次同时完成，也不保证所有应用处在同一时间点。批次内成功条目、失败条目与未处理条目必须分别记录，失败任务不能伪装成完整快照。
