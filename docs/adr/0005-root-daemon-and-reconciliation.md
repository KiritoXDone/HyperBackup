# Root daemon 拥有执行，App 观察并对账

为使页面生命周期与备份执行分离，采用 libsu 6.0.0 daemon RootService + Binder/AIDL，Root 服务持有任务和唯一执行日志，Room 只保存展示投影。替代直接依赖上游菜单会话或把作业放在 ViewModel/普通客户端作用域的做法。

代价是需要显式版本握手、身份与用户校验、提交去重、事件补取、控制会话租约和中断核对。daemon 不能保证跨更新、强停、Root 丢失或设备重启存活；状态不明时不自动重放恢复。此架构决定于 2026-11-08 随整体设计确认，具体存活行为仍需 P0 验证。
